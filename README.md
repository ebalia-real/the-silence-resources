# The Silence — story-mode resources

Encrypted resources (maps, textures, characters, sounds and cinematics) for the story mode of
**The Silence**, a Minecraft Forge 1.20.1 mod by **EBALIA**.

**You don't need to download anything from here.** The mod downloads these files by itself the first
time you play the story mode, checks each one (SHA-256) and keeps them in your game folder
(`the_silence/recursos/`). The files are published here only because they are too big for a single
mod file on CurseForge and Modrinth.

- This repository contains **no code**.
- The files are **encrypted** and can only be read by the mod.
